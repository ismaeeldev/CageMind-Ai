2.1 Fighter Status Breakdown

896
On roster but no recent fight or removed from listing
83
UFC.com hero section explicitly shows “Retired” tag
How Status Is Determined: The system checks each fighter's UFC.com profile hero section first. If the page explicitly says "Retired" → retired. If the page is not found (404) → inactive. If the fighter is on roster, a 4-year last-fight check determines active vs inactive. On page error, the 4-year rule is used as fallback. Only the hero section is checked — never full body text — to prevent false positives from fight history mentioning retired opponents.
